# 문서 관련성 검수 화면

주소: http://127.0.0.1:8765/relevance

기존 화면 위쪽의 ‘다음 단계: 문서 관련성 검수’ 링크로도 이동한다.
경찰민원 107건부터 표시하며 전체 500건으로 전환할 수 있다.

## 판단 방법

왼쪽 민원을 읽고 오른쪽 각 문서에 관련 있음 / 관련 없음 / 판단 보류를 선택한다.
근거가 된 문장이나 무관한 이유를 남기면 후속 검토에 도움이 된다.
일반 포털 안내가 존재한다는 이유만으로 모든 민원에 관련 있다고 판단하지 않는다.
자동 저장 또는 ‘저장하고 다음’으로 기록한다. 기존 6항목 검수 응답은 수정하지 않는다.

첫 후보 목록은 고충민원 범위 기준 1개, 신청방법·민원 창구 안내 2개다.
공식 자료 본문을 확인한 뒤 요약한 텍스트를 보여주며 원문 링크와 해당 구간을 제공한다.
원문 전체를 복제한 자료가 아니며, 원문 확인이 필요하면 카드의 링크로 확인한다.
이 3개 문서는 모든 민원에서 고정된 순서로 제시한다. 검색 순위나 모델 점수로 선정한
후보가 아니고, 완전한 지식 corpus 또는 검수 완료된 유형 기준도 아니다.

출처 확인일: 2026-10-26.

* [고충민원 제도 소개](https://www.acrc.go.kr/menu.es?mid=a10102010100)
* [고충민원 신청방법 안내](https://www.acrc.go.kr/menu.es?mid=a10201010100)
* [국민신문고 소개](https://www.acrc.go.kr/menu.es?mid=a10104030100)

## 저장 및 평가 경계

응답: `.local-data/acrc-human-review/relevance-responses.json` (첫 저장 시 생성).
기존 응답: `.local-data/acrc-human-review/responses.json`.

질의 ID·본문 해시·문서별 판단·이유·검토자·수정 시각·수정 번호를 저장한다.
전체 데이터 해시와 문서 목록 파일 해시를 함께 보존하며 문서가 변경되면 기존 응답을
새 문서에 자동 적용하지 않는다. 동시 수정은 충돌로 알리고 파일은 원자적으로 교체한다.

`completed`는 모든 카드에 응답했다는 뜻이다. `resolved`는 보류 없이 관련/무관을
선택했다는 뜻이다. 미선택 null, 보류 UNSURE, 무관 IRRELEVANT는 서로 다르다.
모든 카드가 무관하더라도 전체 채널 근거 없음이나 사례 없음 정답으로 변환하지 않는다.
VERIFIED_CASE 자료와 경찰 세부 안내가 부족하며, 이용 조건 승인은 별도로 남아 있다.
API 키 호출, 임베딩, 운영 DB 적재 및 성능 지표 계산은 이번 작업에 포함되지 않는다.

개인정보 검수 항목이 PASS인 사례만 이 화면에 표시한다. 기록은 Git 제외 로컬 파일에
저장되고 외부 서비스에 전송하지 않는다. 기존 500건 응답은 서버 재시작 전후 파일 해시가
동일함을 확인했다. 서버 재실행은 `tools/Start-Review.ps1`을 사용한다.
